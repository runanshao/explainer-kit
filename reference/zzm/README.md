# 三张牌 · 张忠谋与台积电的四十年棋局

这是一支讲解视频，根据一份《张忠谋自传》解读文稿制作，主题有两个：张忠谋作为 CEO 的战略，以及台积电夹在中美之间时他怎么下棋。文稿几乎没有地缘政治的内容，这部分全部是联网核对后补上的，逐条出处见 `SOURCES.md`。

现在是 v2「故事版」。v1 是按主题分段的讲解版，画面像动态 PPT，存档在 git 第一个提交和 `out/zzm-v1.mp4`。

## 结构：一个钩子接一个钩子

全片按时间线讲，每一场都停在一个没回答的问题上，下一场开头接住它：

- **序章**（s01）：2022 年亚利桑那沙漠里那句「全球化几乎已死」，然后抛出总悬念——靠全球化起家的人为什么宣布它死亡？片尾一句「那一年，52 岁的张忠谋，丢了工作」，接片名。
- **崛起**（s02–s07）：1983 年失业，接着是 1987 年的 A/B 选择（暂停让观众先猜）、英特尔、1997 年那通电话、2009 年 77 岁复出（第二次暂停）、苹果敲门、请黄仁勋接班。
- **夹缝**（s08–s13）：先摆出棋盘和三张牌，再依次讲中芯官司、去不去大陆、兵家必争之地、断供华为，然后是 2022 年的四句话。第四句回到开场的沙漠，序章埋下的问题在这里收回。最后是亚利桑那。
- **对账与尾声**（s14–s15）：在账簿上逐条盖章，然后留给观众四条原则和一个问题。

## 画面

画面是电影感插画，不用幻灯片。全片加了 2.2:1 黑边，字幕放在下边的黑边里，叠一层胶片颗粒和暗角，色调按年代分：1983 年是旧照片的棕褐色，八十年代到 2013 年偏暖，地缘政治部分偏冷，沙漠用黄昏色。每一场由多个镜头组成，镜头在旁白的 cue 上切换，每个镜头自带缓推的运镜。

视觉母题有三个：张忠谋的剪影带一支烟斗，三股力量画成一张棋盘，三条策略画成三张烫金纸牌。数据都放在片中实物里，比如股权证书、法院和解文书、年报第 105 页、保单和对账簿。

## 基本参数

- 合成 ID `ZhangZhongmou`，1920×1080，30fps，15 场，约 21.6 分钟
- 旁白用 edge-tts `zh-CN-YunjianNeural` +10%。张忠谋的原话用 `zh-TW-YunJheNeural` 读，其他人的引语用 `zh-CN-YunxiNeural`
- 成片 `out/zzm.mp4`（已混配乐），未混音的版本是 `out/zzm-raw.mp4`

## 管线

1. 改旁白：编辑 `tts/script.json`。标记有三种：`[[cue]]` 是镜头切换点；`||` 是戏剧停顿，时长取 `pause`；`<<zc|……>>` 表示这段换引语声音读，键名对应 `voices`。只重做某几场用 `python tts/gen.py s04`。
2. 节奏：`src/pace.json` 控制每场开头章节卡和结尾钩子黑场的帧数。
3. 审图：`node tools/stills.mjs s01 s02` 在每个 cue 后约 2.5 秒出一张图，再用 `python tools/sheet.py s01` 拼成 2×2。只看指定帧用 `node tools/pick.mjs s04:matrix:40`，输出在 `out/pick/`。
4. 渲染：`npm run render`（带 `--gl=angle`，走 GPU 合成，约 25 分钟；纯软件渲染要两个多小时）。然后 `python tools/music.py` 生成 `out/music.wav`，再混音：

```
ffmpeg -i out/zzm-raw.mp4 -i out/music.wav -filter_complex "[1:a]lowpass=f=2400,volume=0.55[m];[m][0:a]sidechaincompress=threshold=0.02:ratio=5:attack=60:release=800[md];[0:a][md]amix=inputs=2:duration=first:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=11[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out/zzm.mp4
```

| 文件 | 作用 |
|---|---|
| `src/film.tsx` | 电影层：`Shots`（按 cue 切镜头）、`Cam`（运镜）、`Graded`（年代调色）、颗粒、黑边、`Place`（年份地点字幕）、`BigQuote`、`Paper`、`Stamp`、`Chapter` |
| `src/art.tsx` | SVG 插画库：天空、山脊、城市天际线、剪影人物（含烟斗和烟）、观众、工厂、门、棋子、棋盘、晶圆、硬币、法院、台湾海峡 |
| `src/sets.tsx` | 复用场景：沙漠、书桌、窗景、棋盘、纸牌、海峡 |
| `src/props.tsx` | 道具：报纸、文书、照片、天平、碗、盾、日历、墨水条形图 |
| `src/scenes/s01–s15.tsx` | 逐场镜头表 |
| `src/lib.tsx` | 时间轴：`c(cue)` 取 cue 帧，`w(词)` 取旁白说到某个词的帧，`rel(词, cue)` 取某个 cue 之后第一次说到这个词的相对帧 |
| `tools/music.py` | 合成配乐：底层氛围音按三幕换和声，紧张段落加心跳脉冲，每场钩子处有上扬音效接低频重击，章节卡响一声钟 |
